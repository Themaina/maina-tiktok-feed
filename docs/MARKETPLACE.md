# Marketplace listing copy (maina888)

**Name:** TikTok Feed
**Plugin id:** `mainasoftwares/tiktok-feed` (existing listing; keep this id so current installs get the update)
**Tagline:** Your TikTok videos in a floating shoppable panel on every page.
**Category:** Marketing / Social
**Price:** Free (MIT)
**Compatibility:** Botble CMS core 7.3.0+, PHP 8.2+, any theme (shop page options need the Ecommerce plugin)

**Short description**
Add a small floating TikTok button to your storefront. It opens a swipeable 9:16 video panel with a "Shop Now" button for each video and a follow link to your profile. Choose the corner, size and pages, and turn on privacy mode to load nothing from TikTok until a shopper taps play.

**Highlights**
- Floating, draggable launcher in any corner, three sizes
- Swipeable video carousel with a shop link per video
- Show on all pages or only on homepage, shop, product, cart or checkout pages
- Privacy mode with cover images: no TikTok request before a tap
- Embeds load only when the panel opens, so pages stay fast
- Phone options: hide on mobile or lift above bottom navigation bars
- Stacks neatly with the Instagram Feed and Facebook Feed plugins
- No API keys, no visitor data stored, clean uninstall
